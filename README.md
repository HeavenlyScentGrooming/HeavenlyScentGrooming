# heavenlyscentgrooming

Website for Heavenly Scent Grooming — mobile pet grooming in Ann Arbor, MI.

**Stack:** Static site on **Cloudflare Pages**, contact API under **`/api/*`**, leads in **D1**, outbound mail via **Gmail SMTP** (App Password). See `functions/api/contact.js`, `schema/leads.sql`, and `functions/shared/gmail-smtp.js` for setup.
